## 不适合谁，以及新手要知道的几件事

先把话说在前面：搬瓦工是自助管理服务，官方自己说这是价格能压下来的原因。你拿到的是一台空 Linux 机器，装环境、配防火墙、出问题排障都靠自己。完全不想碰命令行的人，更适合找托管类平台，多花点钱换省心。

打算自己动手的话，有几件事官方知识库讲得很实在：

1. **一套账号有三层密码**：客户区密码管购买续费，KiwiVM 面板密码管机器管理（其实可以不设，从客户区一键登录面板），root 密码管系统本身。root 密码由面板随机生成强度较高，官方不保存明文，建议改之前想清楚。
2. **别用网页版 Interactive Shell 输密码**——它不支持复制粘贴，密码还不回显。装个 Putty 之类的 SSH 客户端连过去，体验完全不同。
3. **建站系统选型**：官方工程师的经验是 CentOS 更新极少破坏配置，“装好后几年不用动”；Ubuntu/Debian 更新周期短、不一定每次都顺。不过 CentOS 系如今主线已切换，新装机器直接选 AlmaLinux 或 RockyLinux，它们就是 CentOS 的延续，系统可在面板即时重装。
4. **装好系统先做三件事**：改 SSH 默认端口、建一个 sudo 用户并禁用 root 直接登录、用防火墙只放行必要端口。这几步能挡掉绝大多数暴力破解尝试。
